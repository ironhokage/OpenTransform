# OpenDAG

An open source DAG Scene graph for GLM based C++ game engines.

The main goal of this library is to provide upcoming game engine developers with a ready-made transform and scene graph system.

## Why did I start this?

When I started making my own custom engine, that will be available to everyone once its completion, I had come across the hurdle of the transform system,
little information exists on them, so I started researching how big engines handle transforms, and truth be told, it's a lot, 
so to help others avoid the challenges I faced and still do I started making and documenting this system, hoping it will help other people.

> [!IMPORTANT]
> I am a beginner in C++ and this system is far above my current skills, so any issues, errors or inefficiencies seen in the code should be presented in the Issues tab.
